# 股票筛选系统

这是一个基于Flask的股票筛选系统，包含两个主要应用：

## 1. 强者恒强：主升浪龙头猎杀系统 (app.py)

**端口：5000**

### 功能特点：
- 基于腾讯财经接口获取股票数据
- 严格执行量价、均线、抛压与历史新高过滤逻辑
- 支持手动输入股票代码扫描
- 支持一键扫描全市场热门龙头
- 实时展示扫描结果，包括代码、名称、最新价、20日均线、量比、60日新高和状态

## 2. 伏击圈：精准回踩猎杀系统 (app_pullback.py)

**端口：5001**

### 功能特点：
- 核心纪律：不追高、等缩量、踩均线
- 专治手痒，只做右侧确定性低吸
- 基于腾讯财经接口获取股票数据
- 支持手动输入股票代码扫描
- 支持一键扫描全市场黄金坑
- 实时展示扫描结果，包括代码、名称、最新价、MA20防线、均线乖离率、量比和状态

## 技术栈
- Python 3.12+
- Flask
- Requests
- Vue 3 (前端)
- Tailwind CSS (前端)

## 安装与运行

1. **克隆仓库**
   ```bash
   git clone https://github.com/chaucerhe/stock_scanner.git
   cd stock_scanner
   ```

2. **创建虚拟环境**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **安装依赖**
   ```bash
   pip install flask requests
   ```

4. **运行服务**
   - 启动主升浪龙头猎杀系统：
     ```bash
     python app.py
     ```
   - 启动精准回踩猎杀系统：
     ```bash
     python app_pullback.py
     ```

5. **访问系统**
   - 主升浪龙头猎杀系统：http://127.0.0.1:5000
   - 精准回踩猎杀系统：http://127.0.0.1:5001

## 核心过滤逻辑

### 主升浪龙头猎杀系统：
1. 基本面排雷：剔除垃圾股和高价股
2. 拒绝涨停板：涨幅大于8%的直接淘汰
3. 均线通道：必须在MA20上方，但绝对不能偏离MA20太远（限制在2%~10%之间）
4. 温和放量：量比在1.2到3.0之间最健康
5. 极端洗盘与抛压过滤：上影线容忍度
6. 蓄势突破：距离60日新高在8%以内

### 精准回踩猎杀系统：
1. 价格限制：只做50元以下的股票
2. 绝对支撑红线：拒绝任何形式的“破位”
3. 斜率硬指标：拒绝均线走平或低头
4. 日内深度过滤：拒绝日内跌幅过深的“诱多反抽”
5. 战略级底色核查：距高点跌幅超20%的股票
6. 均线死结过滤：5/10/20/30四根均线高度粘合的股票
7. 短线断头铡刀过滤：MA5直接死叉跌穿MA20的股票
8. 头顶泰山压顶过滤：现价被MA5和MA10双重死叉压制的股票
9. 量能极致萎缩：量比不超过0.85
10. 长线牛股基因：MA60必须在MA120上方
11. 波段趋势过滤：MA20必须在MA60上方
12. 情绪过滤：拒绝接暴跌的飞刀，拒绝追高
13. 精准打击区：乖离率不超过3%
